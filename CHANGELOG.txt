==================================================
 SHARKY — CHANGELOG / ИСТОРИЯ ИЗМЕНЕНИЙ
==================================================

Формат: семантические версии в ветке v0.x.0
  - v0.X.0  — новая функциональность / заметные изменения
  - v0.x.Y  — мелкие правки и багфиксы

Версия, которая показывается в приложении, задаётся на экране
загрузки в index.html (элемент .ld-version, id="ld-version").
При каждом релизе:
  1. поднять номер версии в этом файле (новая запись сверху),
  2. обновить строку "Sharky vX.Y.Z" в index.html (.ld-version),
  3. закоммитить и запушить в main (GitHub Pages задеплоит сам).

Новые записи добавляются СВЕРХУ.

--------------------------------------------------
v0.2.1 — 2026-06-21
--------------------------------------------------
Мелкие правки UI ленты:
- Кнопка «скрыть интерфейс» теперь показывает глаз: обычный открытый
  глаз, когда всё видно, и перечёркнутый — когда интерфейс скрыт
  (раньше был квадрат).
- Соц-колонка (аватар автора, лайки, комментарии, шеры, избранное)
  поднята вверх и выровнена по той же правой вертикали, что и кнопки
  пауза/скрыть (идёт сразу под ними), а не висит по центру экрана.
- На кнопке «поделиться» убрана подпись «Поделиться» — теперь там
  всегда счётчик (как у лайков/комментариев); 0, если шеров ещё нет.

--------------------------------------------------
v0.2.0 — 2026-06-21
--------------------------------------------------
Обновление UI ленты (более аккуратный дизайн, по макету из
Claude Design). Только внешний вид — игровая логика, аналитика и
навигация не тронуты.

Добавлено:
- Плашка «играли» в шапке карточки рядом с жанром: зелёная точка-
  индикатор + число (как просмотры видео на YouTube). Число = сколько
  всего сессий длились дольше 3 секунд (active_ms >= 3000), берётся
  через новый публичный RPC public_play_counts() (SECURITY DEFINER,
  отдаёт только агрегат count(*) по game_id — данные пользователей не
  раскрываются). Пока плашка показывается только когда число > 0.
- Новая миграция supabase/migrations/20260621120000_public_play_counts.sql.

Изменено (внешний вид шапки и оверлеев ленты):
- Автор вынесен в «стеклянную» плашку-пилюлю (blur + рамка).
- Жанр — отдельный тег без иконки; рядом плашка «играли».
- Соц-кнопки (лайк/коммент/шер/сохранить) и кнопки сверху
  (пауза/скрыть UI) — скруглённые «стеклянные» квадраты 44px (r:16)
  вместо тёмных кругов. Активный лайк — заливка акцентом (бел. сердце),
  активное сохранение — жёлтая заливка (тёмная закладка).
- Блок счёта: подпись «Счёт», крупнее кернинг; «BEST» → «Рекорд».

--------------------------------------------------
v0.1.1 — 2026-06-18
--------------------------------------------------
Исправлено:
- Подпись версии на экране загрузки не отображалась: была задана
  через position:absolute / bottom и уезжала вниз за пределы видимой
  области. Убрано абсолютное позиционирование — версия теперь стоит
  в общем потоке прямо под точками загрузки.

--------------------------------------------------
v0.1.0 — 2026-06-18
--------------------------------------------------
Первая версионированная сборка Sharky.

Добавлено:
- Экран загрузки: подпись "Swipe and play" под логотипом
  (тег-лайн .ld-tagline). Раньше изменение было только в рабочей
  копии и не попадало на сайт — теперь задеплоено.
- Экран загрузки: подпись версии "Sharky v0.1.0" внизу экрана
  (.ld-version).
- Введена схема версионирования и этот файл CHANGELOG.txt для
  записи результатов всех изменений.

Базовое состояние на момент v0.1.0 (было реализовано ранее, без
номеров версий):
- TikTok-style лента HTML мини-игр, Telegram Mini App.
- Supabase: авторизация через Telegram, RLS, лайки/комментарии/
  подписки/шеры.
- Админ-панель (admin.html) и аналитический дашборд (аудитория +
  игры, dwell-time сессии, app_opens).
- Recsys layer 1: провенанс ленты в game_stats.
